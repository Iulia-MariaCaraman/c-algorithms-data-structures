# C Algorithms and Data Structures Library

Academic implementations developed for Data Structures and Algorithm Analysis at ASE Bucharest.

## Overview
This repository contains reference implementations of fundamental computer science algorithmic paradigms written in C.

## Implemented Paradigms
* Divide and Conquer: Recursive partitioning algorithms for array processing, element counting, and boundary searches.
* Backtracking: Permutation generation with custom non-consecutive value constraints.
* Greedy Strategy: Optimization models for subset selection under weight and capacity limits.
* Graph Algorithms: Graph traversal including Breadth-First Search, Depth-First Search, node degree metrics, and connected components analysis on adjacency matrices.

## Repository Contents
* DET.c: Divide and conquer implementations.
* bkt.c: Backtracking permutations and constraint validation.
* greedy.c: Greedy subset optimization algorithm.
* grafexamen.c: Practical exam implementation of greedy selection.
* FileName.c: Graph representation, matrix loading, BFS, DFS, and connectivity checks.
